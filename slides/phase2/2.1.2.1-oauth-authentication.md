## Why OAuth 2.0?

### The Old Way: Username + Password

```python
# DON'T DO THIS!
username = "admin"
password = "MyPassword123"  # Exposed in code!
```

**Problems:**
- Passwords exposed in code
- Can't limit permissions
- Hard to revoke without changing password
- No expiration

---

## Why OAuth 2.0? (Continued)

### The OAuth Way: Tokens

```python
# Modern approach
access_token = get_token(client_id, client_secret)
# Token has specific permissions and expires
```

**Benefits:**
- No password exposure
- Scoped permissions (principle of least privilege)
- Tokens expire automatically
- Easy to revoke individual tokens

---

## OAuth 2.0 Core Concepts

### Key Components

1. **Client** - Your Python application
2. **Authorization Server** - UiPath Identity Service
3. **Resource Server** - UiPath Orchestrator
4. **Access Token** - Temporary credential
5. **Scopes** - Permissions granted

```
└─────────────────┘
```

## OAuth Grant Types

### Client Credentials (Recommended)

**Use for:** Server-to-server authentication

```
grant_type=client_credentials
```

**Your app authenticates as itself**

### Other Grant Types

- `authorization_code` - User-based auth (web apps)
- `password` - Username/password (legacy)
- `refresh_token` - Token refresh

**For Python SDK: Use client_credentials**

---

## Token Request

### Request Format

**Endpoint:** `POST /identity_/connect/token`

**Headers:**
```
Content-Type: application/x-www-form-urlencoded
```

**Body (form data):**
```
grant_type=client_credentials
client_id=<your_client_id>
client_secret=<your_client_secret>
scope=OR.Jobs OR.Queues OR.Assets
```

---

## Token Request (Continued)

### Python Example with requests

```python
import requests

TOKEN_URL = "https://cloud.uipath.com/identity_/connect/token"

data = {
    "grant_type": "client_credentials",
    "client_id": "your_client_id_here",
    "client_secret": "your_client_secret_here",
    "scope": "OR.Jobs OR.Queues"
}

response = requests.post(TOKEN_URL, data=data)
response.raise_for_status()

token_data = response.json()
access_token = token_data["access_token"]
```

## Token Response

### Successful Response

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIsImtpZCI6IkQ3...",
  "expires_in": 3600,
  "token_type": "Bearer",
  "scope": "OR.Jobs OR.Queues"
}
```

**Key Fields:**
- `access_token` - Use for API calls
- `expires_in` - Seconds until expiration (typically 3600 = 1 hour)
- `token_type` - Always "Bearer"
- `scope` - Granted permissions

## Principle of Least Privilege

### Request Only What You Need

**Bad:**
```python
scope = "OR.Jobs OR.Queues OR.Assets OR.Folders OR.Machines OR.Robots"
# Requesting everything!
```

**Good:**
```python
scope = "OR.Queues"  # Only need queue access
```

**Why?**
- Minimizes damage if token compromised
- Clearer intent
- Better security posture

## Token Expiration

### Access Tokens Expire

**Typical lifetime:** 1 hour (3600 seconds)

**When expired:**
- API returns 401 Unauthorized
- Must request new token

## Token Management Pattern

### Caching Tokens

```python
import time

class TokenManager:
    def __init__(self, client_id, client_secret):
        self.client_id = client_id
        self.client_secret = client_secret
        self.token = None
        self.expires_at = 0

    def get_token(self):
        if time.time() >= self.expires_at:
            self._refresh_token()
        return self.token

    def _refresh_token(self):
        response = self._request_token()
        self.token = response["access_token"]
        self.expires_at = time.time() + response["expires_in"] - 60
```

## Error Handling

### Common Errors

**401 Unauthorized:**
- Invalid or expired token
- Solution: Request new token

**400 Bad Request:**
- Invalid client credentials
- Missing required parameters
- Solution: Check credentials and request format

**403 Forbidden:**
- Token valid but lacks required scope
- Solution: Request token with appropriate scopes

---

## Error Handling (Continued)

### Robust Error Handling

```python
def get_access_token(client_id, client_secret):
    try:
        response = requests.post(
            TOKEN_URL,
            data={
                "grant_type": "client_credentials",
                "client_id": client_id,
                "client_secret": client_secret,
                "scope": "OR.Jobs"
            },
            timeout=10
        )
        response.raise_for_status()
        return response.json()["access_token"]
    except requests.exceptions.HTTPError as e:
        if e.response.status_code == 401:
            raise ValueError("Invalid client credentials")
        elif e.response.status_code == 400:
            raise ValueError(f"Bad request: {e.response.text}")
        raise
    except requests.exceptions.Timeout:
        raise TimeoutError("Token request timed out")
```

## Complete Working Example

```python
import os
import requests
from dotenv import load_dotenv

# Load environment variables
load_dotenv()

# Configuration
TOKEN_URL = "https://cloud.uipath.com/identity_/connect/token"
CLIENT_ID = os.getenv("UIPATH_CLIENT_ID")
CLIENT_SECRET = os.getenv("UIPATH_CLIENT_SECRET")
ORCHESTRATOR_URL = "https://cloud.uipath.com/org/tenant/orchestrator_"

# Get token
def get_token():
    response = requests.post(TOKEN_URL, data={
        "grant_type": "client_credentials",
        "client_id": CLIENT_ID,
        "client_secret": CLIENT_SECRET,
        "scope": "OR.Jobs"
    })
    response.raise_for_status()
    return response.json()["access_token"]

# Use token
token = get_token()
headers = {"Authorization": f"Bearer {token}"}
jobs = requests.get(f"{ORCHESTRATOR_URL}/odata/Jobs", headers=headers)
print(jobs.json())
```

## Security Best Practices

### 1. Secret Management

- Store secrets in .env files
- Add .env to .gitignore
- Use secret managers in production (Azure Key Vault, AWS Secrets Manager)

### 2. Token Handling

- Never log tokens
- Don't include tokens in error messages
- Regenerate compromised tokens immediately

---

## Security Best Practices (Continued)

### 3. Scope Management

- Request minimum necessary scopes
- Review scopes regularly
- Remove unused permissions

### 4. Token Storage

- Never store tokens in:
  - Version control
  - Log files
  - Client-side storage (for web apps)
  - Unencrypted databases

---

## Security Best Practices (Continued)

### 5. Credential Rotation

- Rotate Client Secrets periodically
- Have a rotation process
- Update secrets without downtime

### 6. Monitoring

- Log authentication failures
- Monitor for unusual token usage
- Alert on repeated failures

## Troubleshooting

### Issue 1: 401 Unauthorized

**Symptoms:** Cannot get token

**Checklist:**
- [ ] Client ID correct?
- [ ] Client Secret correct (no extra spaces)?
- [ ] External Application not disabled?
- [ ] Correct token endpoint URL?

---

## Troubleshooting (Continued)

### Issue 2: Token Works But API Calls Fail

**Symptoms:** Token obtained but 403 on API calls

**Checklist:**
- [ ] Requested scope includes needed permissions?
- [ ] External Application has required scopes enabled?
- [ ] Using correct organization/tenant in API URL?
- [ ] Folder context set if required?

---

## Troubleshooting (Continued)

### Issue 3: Intermittent Failures

**Symptoms:** Works sometimes, fails others

**Likely Cause:** Token expiration

**Solution:**
- Implement token caching with expiration check
- Refresh token proactively before expiration
- Handle 401 by refreshing token and retrying

```python
import os
import time
import requests
from dotenv import load_dotenv

load_dotenv()

class OAuthClient:
    def __init__(self):
        self.client_id = os.getenv("UIPATH_CLIENT_ID")
        self.client_secret = os.getenv("UIPATH_CLIENT_SECRET")
        self.token_url = "https://cloud.uipath.com/identity_/connect/token"
        self.token = None
        self.expires_at = 0

        if time.time() >= self.expires_at:
            self._request_new_token()
        return self.token
```
