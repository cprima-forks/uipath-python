## Output Arguments Overview

### What Are Output Arguments?

**In UiPath Studio:**
- Define output arguments (e.g., `out_ResultCount`, `out_Data`)
- Process assigns values during execution
- Returned when job completes

**Via API:**
- Stored in job's `OutputArguments` field
- Available after job reaches Successful state
- Formatted as JSON string

## Accessing Output Arguments

### Basic Example


## Safe Parsing Pattern

### Handling Edge Cases

```python
import json

def get_job_outputs(job):
    """Safely extract and parse output arguments"""
    
    # Check job succeeded
    if job['State'] != 'Successful':
        return None
    
    # Get OutputArguments (might be None or empty string)
    output_json = job.get('OutputArguments')
    
    if not output_json:
        return {}  # Empty dict for no outputs
    
    try:
        # Parse JSON
        outputs = json.loads(output_json)
        return outputs
    except json.JSONDecodeError as e:
        print(f"Invalid OutputArguments JSON: {e}")
        return None
```

## Output Validation

### Why Validate?

**Even successful jobs can have issues:**
- Missing expected outputs
- Wrong data types
- Out-of-range values
- Partial failures

**Best practice:** Always validate outputs

---

## Output Validation Pattern

### Comprehensive Validation

```python
def validate_outputs(outputs, expected_schema):
    """
    Validate job outputs against expected schema
    
    Args:
        outputs: Parsed output arguments dict
        expected_schema: Dict of {key: type} or {key: validator_func}
    
    Returns:
        List of validation errors (empty if valid)
    """
    errors = []
    
    for key, expected_type in expected_schema.items():
        # Check key exists
        if key not in outputs:
            errors.append(f"Missing required output: {key}")
            continue
        
        value = outputs[key]
        
        # Check type
        if not isinstance(value, expected_type):
            errors.append(
                f"Output {key} has wrong type: "
                f"expected {expected_type}, got {type(value)}"
            )
    
    return errors
```

## Parsing Error Details

### Extracting Key Information

```python
def parse_error_info(error_info):
    """Extract structured error data"""
    
    lines = error_info.split('\n')
    
    # First line usually has exception type and message
    first_line = lines[0] if lines else ''
    
    # Try to extract exception type
    if ':' in first_line:
        exc_type, exc_message = first_line.split(':', 1)
        exc_type = exc_type.strip()
        exc_message = exc_message.strip()
    else:
        exc_type = 'Unknown'
        exc_message = first_line
    
    return {
        'exception_type': exc_type,
        'message': exc_message,
        'full_trace': error_info
    }
```

## Processing Robot Logs

### Analyzing Log Entries

```python
def get_job_logs(orchestrator_url, token, folder_id, job_key):
    """Retrieve and process job logs"""
    
    response = requests.get(
        f"{orchestrator_url}/odata/RobotLogs",
        headers={
            "Authorization": f"Bearer {token}",
            "X-UIPATH-OrganizationUnitId": str(folder_id)
        },
        params={
            "$filter": f"JobKey eq '{job_key}'",
            "$orderby": "TimeStamp asc"
        }
    )
    
    logs = response.json()['value']
    
    # Group by level
    by_level = {}
    for log in logs:
        level = log['Level']
        if level not in by_level:
            by_level[level] = []
        by_level[level].append(log)
    
    return by_level
```

## Execution Metrics

### Calculating Duration

```python
from datetime import datetime

def calculate_duration(job):
    """Calculate job execution time"""
    
    if not job.get('EndTime'):
        return None  # Job not finished
    
    start = datetime.fromisoformat(
        job['StartTime'].replace('Z', '+00:00')
    )
    end = datetime.fromisoformat(
        job['EndTime'].replace('Z', '+00:00')
    )
    
    duration = end - start
    
    return {
        'seconds': duration.total_seconds(),
        'formatted': str(duration)
    }
```

## Complete Result Handler

### Unified Pattern

```python
def handle_job_result(job):
    """
    Comprehensive job result handling
    
    Returns:
        dict with status, outputs, errors, metrics
    """
    result = {
        'job_id': job['Key'],
        'state': job['State'],
        'robot': job['Robot']['Name'],
        'outputs': None,
        'error': None,
        'duration': None
    }
    
    # Calculate duration
    result['duration'] = calculate_duration(job)
    
    # Handle by state
    if job['State'] == 'Successful':
        # Parse outputs
        result['outputs'] = get_job_outputs(job)
        
        # Validate
        if result['outputs']:
            validation_errors = validate_outputs(
                result['outputs'],
                EXPECTED_SCHEMA
            )
            if validation_errors:
                result['validation_errors'] = validation_errors
    
    elif job['State'] == 'Faulted':
        # Parse error
        result['error'] = parse_error_info(job.get('Info', ''))
    
    return result
```

## Best Practices

### 1. Always Parse Safely

```python
# ✗ Unsafe
outputs = json.loads(job['OutputArguments'])

# ✓ Safe
output_json = job.get('OutputArguments')
if output_json:
    try:
        outputs = json.loads(output_json)
    except json.JSONDecodeError:
        outputs = None
```

## Troubleshooting

### Issue 1: OutputArguments is null

**Causes:**
- Process has no output arguments defined
- Job hasn't finished yet
- API response incomplete

**Solution:**
Check job state first, then handle null/empty gracefully

---

## Troubleshooting (Continued)

### Issue 2: JSON parsing fails

**Error:** `json.JSONDecodeError`

**Causes:**
- Malformed JSON from process
- Special characters not escaped
- Encoding issues

**Solution:**
```python
try:
    outputs = json.loads(output_json)
except json.JSONDecodeError as e:
    logger.error(f"Invalid JSON: {e}")
    logger.debug(f"Raw OutputArguments: {output_json}")
    # Handle error
```

---

## Troubleshooting (Continued)

### Issue 3: Unexpected data types

**Problem:** Expected int, got string

**Solution:** Type conversion with validation
```python
count_str = outputs.get('out_Count', '0')
try:
    count = int(count_str)
except ValueError:
    logger.warning(f"Invalid count value: {count_str}")
    count = 0
```
