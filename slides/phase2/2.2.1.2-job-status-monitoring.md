## Job States Explained

| State | Meaning |
|-------|---------|
| **Pending** | Waiting for available robot |
| **Running** | Process currently executing |

## Polling Pattern

### Basic Concept

**Poll** = Repeatedly check status until terminal state

```python
while True:
    job = get_job_status(job_id)

    if job['State'] in ['Successful', 'Faulted', 'Stopped']:
        break  # Terminal state reached

    time.sleep(2)  # Wait before next check
```

---

## Terminal vs Non-Terminal States

### Terminal States (Stop Polling)

- **Successful** - Job completed
- **Faulted** - Job failed
- **Stopped** - Job canceled

### Non-Terminal States (Continue Polling)

- **Pending** - Still waiting
- **Running** - Still executing
- **Stopping** - Being canceled

## Implementing wait_for_job

### Basic Version

```python
import time

def wait_for_job(
    orchestrator_url,
    token,
    folder_id,
    job_id,
    poll_interval=2
):
    """Wait for job to reach terminal state"""

    while True:
        # Get current status
        response = requests.get(
            f"{orchestrator_url}/odata/Jobs({job_id})",
            headers={
                "Authorization": f"Bearer {token}",
                "X-UIPATH-OrganizationUnitId": str(folder_id)
            }
        )
        response.raise_for_status()

        job = response.json()
        state = job['State']

        print(f"Job {job_id}: {state}")

        # Check for terminal state
        if state in ['Successful', 'Faulted', 'Stopped']:
            return job

        # Wait before next poll
        time.sleep(poll_interval)
```

```python
def wait_for_job(
    orchestrator_url,
    token,
    folder_id,
    job_id,
    poll_interval=2,
    timeout=300  # 5 minutes default

    """Wait for job with timeout"""
    start_time = time.time()

        # Check timeout

            raise TimeoutError(
                f"Job {job_id} did not complete within {timeout}s"
            )

        # Get status
        job = get_job_status(orchestrator_url, token, folder_id, job_id)
        state = job['State']

        # Check for terminal state
        if state in ['Successful', 'Faulted', 'Stopped']:
            return job

        time.sleep(poll_interval)
```

## Complete wait_for_job Function

```python
import time
import logging

logger = logging.getLogger(__name__)

def wait_for_job(
    orchestrator_url,
    token,
    folder_id,
    job_id,
    poll_interval=2,
    timeout=300
):
    """
    Wait for job completion with timeout

    Returns:
        dict: Final job object

    Raises:
        TimeoutError: If job doesn't complete in time
        RuntimeError: If job faults
    """
    start_time = time.time()
    last_state = None

    while True:
        elapsed = time.time() - start_time

        if elapsed > timeout:
            raise TimeoutError(
                f"Job {job_id} timeout after {elapsed:.1f}s"
            )

        # Get current status
        job = get_job_status(orchestrator_url, token, folder_id, job_id)
        state = job['State']

        # Log state changes
        if state != last_state:
            logger.info(f"Job {job_id} state: {state}")
            last_state = state

        # Terminal states
        if state == 'Successful':
            logger.info(f"Job {job_id} completed successfully")
            return job

        elif state == 'Faulted':
            error = job.get('Info', 'Unknown error')
            logger.error(f"Job {job_id} faulted: {error}")
            raise RuntimeError(f"Job execution failed: {error}")

        elif state == 'Stopped':
            logger.warning(f"Job {job_id} was stopped")
            return job

        # Non-terminal - continue polling
        time.sleep(poll_interval)
```

## Monitoring Multiple Jobs (Continued)

### Concurrent Polling

```python
def wait_for_all_jobs(
    orchestrator_url,
    token,
    folder_id,
    job_ids,
    poll_interval=2,
    timeout=300
):
    """Wait for multiple jobs concurrently"""

    start_time = time.time()
    pending_jobs = set(job_ids)
    results = {}

    while pending_jobs:
        if time.time() - start_time > timeout:
            raise TimeoutError(f"{len(pending_jobs)} jobs still running")

        # Check all pending jobs
        for job_id in list(pending_jobs):
            job = get_job_status(orchestrator_url, token, folder_id, job_id)

            if job['State'] in ['Successful', 'Faulted', 'Stopped']:
                # Job finished
                pending_jobs.remove(job_id)
                results[job_id] = job
                print(f"Job {job_id} finished: {job['State']}")

        if pending_jobs:
            time.sleep(poll_interval)

    return results
```

## Usage: Multiple Jobs


## Best Practices

### 1. Appropriate Poll Interval

```python
# Too fast - wastes API calls
poll_interval = 0.1  # ❌ Every 100ms

# Too slow - delays detection
poll_interval = 60   # ❌ Every minute

# Just right
poll_interval = 2    # ✓ Every 2-5 seconds
```

---

## Best Practices (Continued)

### 2. Always Set Timeouts

```python
# No timeout - could wait forever
wait_for_job(job_id)  # ❌

# With reasonable timeout
wait_for_job(job_id, timeout=600)  # ✓ 10 minutes
```

### 3. Log State Changes

```python
if state != last_state:
    logger.info(f"Job {job_id}: {last_state} → {state}")
    last_state = state
```

## Best Practices (Continued)

### 4. Handle All Terminal States

```python
if state == 'Successful':
    return job

    raise RuntimeError(f"Job failed: {job['Info']}")
```

### 5. Implement Retry Logic (Optional)

```python
max_retries = 3
for attempt in range(max_retries):
    try:
        job = wait_for_job(...)

        else:
            raise
```

## Optimization: Exponential Backoff

### For Long-Running Jobs

```python
def wait_with_backoff(job_id, max_interval=30):
    interval = 2  # Start with 2 seconds

    while True:
        job = get_job_status(job_id)

        if is_terminal(job['State']):
            return job

        time.sleep(interval)

        # Increase interval gradually
        interval = min(interval * 1.5, max_interval)
```

**Benefit:** Less API load for long jobs
