## Installation Methods

### Two Primary Methods:

1. **pip** - Standard Python package installer
   - Widely used
   - Well-documented
   - Comes with Python

2. **uv** - Fast Python package installer
   - 10-100x faster than pip
   - Written in Rust
   - Drop-in pip replacement

---

## Method 1: Installing with pip

### Basic Installation

```bash
# Install the UiPath SDK
pip install uipath
```

### With Virtual Environment (Recommended)

```bash
# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (macOS/Linux)
source venv/bin/activate

# Install SDK
pip install uipath
```

---

## Why Use Virtual Environments?

**Problem Without Virtual Environments:**
- Global package installation
- Dependency conflicts between projects
- Difficulty managing different SDK versions

**Benefits of Virtual Environments:**
- **Isolation:** Each project has its own dependencies
- **Version Control:** Different projects can use different SDK versions
- **Cleanliness:** No global package pollution
- **Reproducibility:** Easy to replicate environments

---

## pip Installation: Step-by-Step

```bash
# 1. Create project directory
mkdir my-uipath-project
cd my-uipath-project

# 2. Create virtual environment
python -m venv venv

# 3. Activate virtual environment
source venv/bin/activate  # macOS/Linux
# or
venv\Scripts\activate  # Windows

# 4. Install SDK
pip install uipath

# 5. Verify installation
uipath --version
```

---

## Method 2: Installing with uv

### What is uv?

- **Fast:** 10-100x faster than pip
- **Rust-based:** Compiled, highly optimized
- **Compatible:** Drop-in replacement for pip
- **Modern:** Built for contemporary Python workflows

**Installation:**
```bash
# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install uv (Windows)
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

---

## uv Installation: Step-by-Step

```bash
# 1. Create virtual environment with uv
uv venv

# 2. Activate virtual environment
source .venv/bin/activate  # macOS/Linux
# or
.venv\Scripts\activate  # Windows

# 3. Install SDK with uv
uv pip install uipath

# 4. Verify installation
uipath --version
```

---

## Speed Comparison: pip vs uv

```bash
# pip installation time
time pip install uipath
# Typical: 15-30 seconds

# uv installation time
time uv pip install uipath
# Typical: 2-5 seconds
```

**uv advantages:**
- Parallel downloads
- Optimized dependency resolution
- Cached builds
- Rust performance

## Common Installation Issues

### Issue 1: Command Not Found

**Symptom:**
```bash
uipath --version
# bash: uipath: command not found
```

**Cause:** Python Scripts directory not in PATH

**Solution:**
```bash
# Add to PATH (macOS/Linux)
export PATH="$PATH:$HOME/.local/bin"

# Or use python -m
python -m uipath --version
```

---

## Common Installation Issues (Continued)

### Issue 2: Permission Denied

**Symptom:**
```bash
pip install uipath
# ERROR: Could not install packages due to an EnvironmentError: [Errno 13] Permission denied
```

**Cause:** Trying to install globally without permissions

**Solution 1:** Use virtual environment (recommended)
```bash
python -m venv venv
source venv/bin/activate
pip install uipath
```

**Solution 2:** User installation
```bash
pip install --user uipath
```

---

## Common Installation Issues (Continued)

### Issue 3: Python Version Mismatch

**Symptom:**
```
ERROR: Package 'uipath' requires a different Python: 3.7.0 not in '>=3.8'
```

**Solution:** Upgrade Python

```bash
# Check version
python --version

# Install Python 3.10+ from python.org
# Or use pyenv for version management
```

---

## Common Installation Issues (Continued)

### Issue 4: SSL Certificate Errors

**Symptom:**
```
SSL: CERTIFICATE_VERIFY_FAILED
```

**Solution (Corporate Networks):**
```bash
# Use trusted host (temporary workaround)
pip install --trusted-host pypi.org --trusted-host files.pythonhosted.org uipath
```

**Better Solution:**
- Configure corporate proxy
- Install corporate CA certificates
- Use company's PyPI mirror

## Best Practices

### 1. Always Use Virtual Environments

```bash
# Per-project isolation
python -m venv venv
source venv/bin/activate
pip install uipath
```

### 2. Pin Versions in requirements.txt

```txt
# requirements.txt
uipath==0.2.0
```

---

## Best Practices (Continued)

### 3. Use Lock Files

```bash
# Generate lock file with uv
uv pip compile requirements.in -o requirements.txt

# Install from lock file
uv pip sync requirements.txt
```

### 4. Document Installation Steps

```markdown
# README.md

## Installation

1. Python 3.10+ required
2. Create venv: `python -m venv venv`
3. Activate: `source venv/bin/activate`
4. Install: `pip install -r requirements.txt`
```
