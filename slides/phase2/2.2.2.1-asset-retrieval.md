## What Are Assets?

### Centralized Configuration

**Assets** are configuration values stored in Orchestrator

**Key Characteristics:**
- Centralized management
- Separated from process code
- Environment-specific values
- Secure credential storage
- Dynamic updates without redeployment

---

## What Are Assets? (Continued)

### The Problem Assets Solve

**Without Assets:**
```python
# Hardcoded in process
database_url = "https://prod-db.company.com"
api_key = "abc123secret"  # 😱 Exposed!
```

**Problems:**
- Different values per environment require code changes
- Secrets exposed in code
- No centralized management

---

## What Are Assets? (Continued)

### With Assets

**In Orchestrator:**
- Create asset "DatabaseURL" = "https://prod-db.company.com"
- Create credential asset "APICredential" = username/password

**In Process:**
```python
# Retrieve from Orchestrator
database_url = get_asset("DatabaseURL")
api_credential = get_asset("APICredential")
```

**Benefits:**
- Change values without redeploying
- Different values per environment
- Secure credential handling

## Asset Types

### Four Core Types

1. **Text**
   - String values
   - URLs, file paths, any text data

2. **Bool**
   - True/false values
   - Feature flags, boolean config

3. **Integer**
   - Whole number values
   - Timeouts, retry counts, limits

4. **Credential**
   - Username + password pairs
   - Secure credential storage

## Asset Scoping

### Three Scope Levels

1. **Global**
   - Available to all robots in all folders
   - Default configuration

2. **Per Folder**
   - Specific to a folder (Organization Unit)
   - Overrides global values in that folder

3. **Per Robot**
   - Specific to individual robots
   - Most specific, highest precedence

---

## Asset Scoping (Continued)

### Precedence Rules

When multiple assets with the same name exist:

```
Per Robot > Per Folder > Global
```

**Example:**
- Global: DatabaseURL = "https://db.company.com"
- Dev Folder: DatabaseURL = "https://dev-db.company.com"
- Production Folder: DatabaseURL = "https://prod-db.company.com"

Robots in Dev folder get dev URL, Production robots get prod URL

## Retrieving an Asset by Name

### Using OData Filter

```python
import requests

def get_asset(orchestrator_url, token, folder_id, asset_name):
    """Retrieve a single asset by name"""

    response = requests.get(
        f"{orchestrator_url}/odata/Assets",
        headers={
            "Authorization": f"Bearer {token}",
            "X-UIPATH-OrganizationUnitId": str(folder_id)
        },
        params={
            "$filter": f"Name eq '{asset_name}'"
        }
    )

    response.raise_for_status()
    data = response.json()

    # Check if asset exists
    if not data['value']:
        raise ValueError(f"Asset '{asset_name}' not found")

    return data['value'][0]
```

## Extracting Asset Values (Continued)

### Type-Safe Extraction

```python
def get_asset_value(orchestrator_url, token, folder_id,
                     asset_name, expected_type=None):
    """Get asset value with type validation"""

    asset = get_asset(orchestrator_url, token, folder_id, asset_name)

    value = asset['Value']
    asset_type = asset['ValueType']

    # Validate type if specified
    if expected_type and asset_type != expected_type:
        raise TypeError(
            f"Asset '{asset_name}' is {asset_type}, "
            f"expected {expected_type}"
        )

    return value
```

## Credential Assets

### Special Handling

**Security Rule:**
- Username: **Returned** by API
- Password: **NEVER returned** by API

```python
asset = get_asset(url, token, folder_id, "APICredential")

print(asset['ValueType'])  # "Credential"
print(asset['CredentialUsername'])  # "api_user"
print(asset['CredentialPassword'])  # "" (empty, never exposed)
```

**Passwords are only available to robots during execution**

---

## Credential Assets (Continued)

### When Can Credentials Be Used?

**Via API:** Username only
- You can retrieve username
- Password is never exposed

**Via Robot:** Full credential
- During process execution
- Robot has secure access to password
- Used with Get Credential activity in Studio

**Design Implication:**
- Python SDK cannot directly use credential passwords
- Must pass credential name to robot process
- Robot retrieves full credential during execution

## Retrieving Multiple Assets

### Batch Retrieval

```python
def get_multiple_assets(orchestrator_url, token, folder_id, asset_names):
    """Retrieve multiple assets in one call"""

    # Build filter: Name in ('Asset1','Asset2','Asset3')
    names_quoted = "','".join(asset_names)
    filter_query = f"Name in ('{names_quoted}')"

    response = requests.get(
        f"{orchestrator_url}/odata/Assets",
        headers={
            "Authorization": f"Bearer {token}",
            "X-UIPATH-OrganizationUnitId": str(folder_id)
        },
        params={"$filter": filter_query}
    )

    response.raise_for_status()
    assets = response.json()['value']

    # Convert to dictionary for easy access
    return {asset['Name']: asset for asset in assets}
```

## Error Handling

### Asset Not Found

```python
def get_asset_safe(orchestrator_url, token, folder_id, asset_name):
    """Get asset with error handling"""

    try:
        asset = get_asset(orchestrator_url, token, folder_id, asset_name)
        return asset['Value']

        # API error
```

## Caching Assets

### Why Cache?

**Problem:**
- Assets rarely change
- Retrieving on every use is inefficient
- Unnecessary API calls

**Solution:**
- Cache assets at startup
- Refresh periodically or on demand

---

## Caching Assets (Continued)

### Simple Cache Implementation

```python
class AssetCache:
    def __init__(self, orchestrator_url, token, folder_id):
        self.orchestrator_url = orchestrator_url
        self.token = token
        self.folder_id = folder_id
        self._cache = {}

    def get(self, asset_name, force_refresh=False):
        """Get asset from cache or fetch if not cached"""

        if force_refresh or asset_name not in self._cache:
            # Fetch from Orchestrator
            asset = get_asset(
                self.orchestrator_url, self.token,
                self.folder_id, asset_name
            )
            self._cache[asset_name] = asset['Value']

        return self._cache[asset_name]

    def clear(self):
        """Clear the cache"""
        self._cache.clear()
```

---

## Caching Assets (Continued)

### Usage

```python
# Create cache
asset_cache = AssetCache(orchestrator_url, token, folder_id)

# First call fetches from Orchestrator

# Second call returns cached value (no API call)
```

## Time-Based Cache

### Cache with TTL (Time-To-Live)

```python
import time

class TimedAssetCache:
    def __init__(self, orchestrator_url, token, folder_id, ttl_seconds=300):
        self.orchestrator_url = orchestrator_url
        self.token = token
        self.folder_id = folder_id
        self.ttl_seconds = ttl_seconds
        self._cache = {}
        self._timestamps = {}

    def get(self, asset_name):
        """Get asset, refresh if expired"""

        now = time.time()

        # Check if cached and not expired
        if asset_name in self._cache:
            age = now - self._timestamps[asset_name]
            if age < self.ttl_seconds:
                return self._cache[asset_name]

        # Fetch fresh value
        asset = get_asset(
            self.orchestrator_url, self.token,
            self.folder_id, asset_name
        )
        self._cache[asset_name] = asset['Value']
        self._timestamps[asset_name] = now

        return self._cache[asset_name]
```

## Configuration Class Pattern

### Unified Configuration

```python
class AppConfiguration:
    """Application configuration using Orchestrator assets"""

    def __init__(self, orchestrator_url, token, folder_id):
        self.cache = AssetCache(orchestrator_url, token, folder_id)

    @property
    def database_url(self):
        return self.cache.get("DatabaseURL")

    @property
    def max_retries(self):
        return self.cache.get("MaxRetries")

    @property
    def timeout_seconds(self):
        return self.cache.get("TimeoutSeconds")

    @property
    def notifications_enabled(self):
        return self.cache.get("EnableNotifications")

    def refresh(self):
        """Refresh all cached assets"""
        self.cache.clear()
```

## Best Practices

### 1. Use Assets for Configuration

```python
# ✓ Good: Configuration in assets
```

## Best Practices (Continued)

### 3. Handle Missing Assets

```python

                                  "Timeout", default_value=30)
```

- [ ] Correct folder context (X-UIPATH-OrganizationUnitId)

## Integration Example

### Complete Asset Management Module

```python
# assets.py
import requests
from typing import Any, Dict, List, Optional

class AssetManager:
    """Centralized asset management"""

    def __init__(self, orchestrator_url: str, token: str, folder_id: int):
        self.orchestrator_url = orchestrator_url
        self.token = token
        self.folder_id = folder_id
        self._cache: Dict[str, Any] = {}

    def get(self, name: str, default: Any = None) -> Any:
        """Get asset value with optional default"""
        try:
            if name not in self._cache:
                asset = self._fetch_asset(name)
                self._cache[name] = asset['Value']
            return self._cache[name]
        except ValueError:
            if default is not None:
                return default
            raise
```

## Integration Example (Continued)

```python
    def _fetch_asset(self, name: str) -> Dict:
```
