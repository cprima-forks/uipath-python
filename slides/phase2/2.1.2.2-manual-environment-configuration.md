## Anti-Pattern: Hardcoded Values

### ❌ Don't Do This

```python
# main.py
ORCHESTRATOR_URL = "https://prod.uipath.com/..."
CLIENT_ID = "abc123"
CLIENT_SECRET = "secret123"  # Secret in code!
TIMEOUT = 30

# To switch environments: Edit code and redeploy 😱
```

**Problems:**
- Secrets exposed in code
- Must change code to switch environments
- No separation of configuration and code
- Difficult to manage

---

## The 12-Factor App Approach

### Configuration Principle

> Store config in environment variables

**Benefits:**
- Clear separation of config and code
- Easy environment switching
- No secrets in version control
- Standard practice across languages

**Reference:** [https://12factor.net/config](https://12factor.net/config)

---

## Configuration Strategy

### Three-Layer Approach

1. **.env files** - Secret values (not committed)
2. **Config class** - Load and validate (committed)
3. **Application code** - Use config (committed)

**Separation of concerns!**

## Configuration Class

### Centralized Config Management

```python
# config.py
import os
from dotenv import load_dotenv

class OrchestratorConfig:
    def __init__(self, env_file=None):
        if env_file:
            load_dotenv(env_file)
        else:
            load_dotenv()  # Loads .env by default

        # Load required variables
        self.orchestrator_url = self._get_required("ORCHESTRATOR_URL")
        self.folder = self._get_required("ORCHESTRATOR_FOLDER")
        self.client_id = self._get_required("UIPATH_CLIENT_ID")
        self.client_secret = self._get_required("UIPATH_CLIENT_SECRET")

        # Load optional with defaults
        self.environment = os.getenv("ENVIRONMENT", "dev")
        self.log_level = os.getenv("LOG_LEVEL", "INFO")
        self.api_timeout = int(os.getenv("API_TIMEOUT", "30"))
        self.max_retries = int(os.getenv("MAX_RETRIES", "3"))
```

---

## Configuration Class (Continued)

### Validation Helper

```python
    def _get_required(self, key):
        value = os.getenv(key)
        if not value:
            raise ValueError(f"Required environment variable '{key}' not set")
        return value

    def validate(self):
        """Validate configuration values"""
        if not self.orchestrator_url.startswith('https://'):
            raise ValueError("Orchestrator URL must use HTTPS")

        if self.api_timeout < 1 or self.api_timeout > 300:
            raise ValueError("API timeout must be between 1 and 300 seconds")

        if self.max_retries < 0:
            raise ValueError("Max retries must be non-negative")

        return True
```

---

## Configuration Class (Continued)

### Usage Pattern

```python
    def __repr__(self):
        """String representation (hide secrets!)"""
        return (
            f"OrchestratorConfig("
            f"url={self.orchestrator_url}, "
            f"folder={self.folder}, "
            f"environment={self.environment}, "
            f"client_id={self.client_id[:8]}..., "  # Partial
            f"client_secret=***"  # Hidden
            ")"
        )
```

**Never log full secrets!**

## Type Conversion

### Environment Variables are Strings

```python
# ❌ Wrong - will be string "True" or "False"
DEBUG = os.getenv("DEBUG")

# ✓ Correct - convert to boolean
def str_to_bool(value):
    return value.lower() in ('true', '1', 'yes')

DEBUG = str_to_bool(os.getenv("DEBUG", "False"))

# ✓ Correct - convert to int with default
TIMEOUT = int(os.getenv("API_TIMEOUT", "30"))

# ✓ Correct - convert to float
RETRY_DELAY = float(os.getenv("RETRY_DELAY", "1.5"))
```

## Configuration Validation

### Fail Fast at Startup

```python
# main.py
def main():
    try:
        # Load configuration
        config = OrchestratorConfig()

        # Validate immediately
        config.validate()

        # Run application
        run_app(config)

    except ValueError as e:
        print(f"Configuration error: {e}")
        print("Please check your .env file")
        sys.exit(1)
```

**Fail fast:** Catch issues immediately, not during execution

## Advanced Validation

### Pydantic for Type Safety

```python
from pydantic import BaseSettings, Field, validator

class OrchestratorConfig(BaseSettings):
    orchestrator_url: str = Field(..., regex=r'^https://')
    folder: str
    client_id: str
    client_secret: str
    api_timeout: int = Field(default=30, ge=1, le=300)
    max_retries: int = Field(default=3, ge=0, le=10)

    @validator('orchestrator_url')
    def validate_url(cls, v):
        if not v.endswith('/orchestrator_'):
            raise ValueError("URL must end with /orchestrator_")
        return v

    class Config:
        env_file = '.env'
        case_sensitive = False
```

## Azure Key Vault Example

```python
from azure.identity import DefaultAzureCredential
from azure.keyvault.secrets import SecretClient

def load_from_keyvault(vault_url):
    credential = DefaultAzureCredential()
    client = SecretClient(vault_url=vault_url, credential=credential)

    return {
        'client_id': client.get_secret("uipath-client-id").value,
        'client_secret': client.get_secret("uipath-client-secret").value
    }

# Use in production
if os.getenv('ENVIRONMENT') == 'prod':
    secrets = load_from_keyvault(os.getenv('KEY_VAULT_URL'))
    config = OrchestratorConfig(**secrets)
else:
    config = OrchestratorConfig()  # From .env
```

## Configuration Precedence

### Priority Order

1. **System environment variables** (highest)
2. **.env file values**
3. **Default values** (lowest)

```python
# System env var overrides .env file
# Useful for containers and CI/CD

# .env file
API_TIMEOUT=30

# Container start
docker run -e API_TIMEOUT=60 myapp
# Uses 60, not 30 from .env
```

## Best Practices

### 1. Never Commit Secrets

```bash
# .gitignore
.env
.env.*
!.env.example
*.pem
*.key
```

### 2. Document Required Variables

```bash
# .env.example with descriptions
ORCHESTRATOR_URL=  # Full URL including /orchestrator_
UIPATH_CLIENT_ID=  # From External Application
```

---

## Best Practices (Continued)

### 3. Validate Early

```python
config = OrchestratorConfig()
config.validate()  # Before doing any work
```

### 4. Use Type Safety

```python
from pydantic import BaseSettings
# Automatic validation and type conversion
```

### 5. Hide Secrets in Logs

```python
print(f"Using client ID: {client_id[:8]}...")  # Partial
print(f"Client secret: ***")  # Hidden
```

---

## Best Practices (Continued)

### 6. Environment-Specific Defaults

```python
if config.environment == 'prod':
    log_level = 'INFO'
    timeout = 60
else:
    log_level = 'DEBUG'
    timeout = 30
```

### 7. Rotate Secrets Regularly

- Change credentials quarterly
- Use different credentials per environment
- Revoke old credentials after rotation

## Complete Example (Continued)

```python
# main.py
import sys
from config import OrchestratorConfig
from orchestrator_client import OrchestratorClient

def main():
    # Load environment-specific config
    env = sys.argv[1] if len(sys.argv) > 1 else 'dev'
    env_file = f'.env.{env}'

    try:
        config = OrchestratorConfig(_env_file=env_file)
        print(f"Loaded config for {config.environment}")

        # Create client
        client = OrchestratorClient(config)

        # Run application
        run_app(client, config)

    except Exception as e:
        print(f"Error: {e}")
        sys.exit(1)

if __name__ == "__main__":
    main()
```
