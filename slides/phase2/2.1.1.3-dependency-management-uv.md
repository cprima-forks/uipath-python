## The Dependency Challenge

**Scenario:**
```txt
# Your requirements.txt
uipath>=0.2.0
langchain>=0.1.0
```

**Hidden Reality:**
- uipath depends on: httpx, pydantic, click, ...
- langchain depends on: pydantic, httpx, tenacity, ...
- Each dependency has its own dependencies...

**Result:** 50+ packages installed from 2 requirements

## Why uv?

### pip's Limitations

- **Slow:** Sequential downloads
- **Inefficient:** Rebuilds packages frequently
- **Complex conflicts:** Difficult to debug

### uv's Advantages

- **Fast:** Parallel downloads, Rust performance (10-100x faster)
- **Smart:** Optimized dependency resolution
- **Cached:** Global cache prevents redundant builds
- **Modern:** Built for contemporary workflows

## Generating Lock Files

### Create requirements.in

```txt
# requirements.in
# High-level dependencies with version ranges

uipath>=0.2.0,<1.0.0
python-dotenv>=1.0.0
```

### Compile to Lock File

```bash
uv pip compile requirements.in -o requirements.txt
```

**Result:** requirements.txt with all dependencies pinned

## Using Lock Files

### Install from Lock File

```bash
uv pip install -r requirements.txt
```

**OR** use sync for exact matching:

```bash
uv pip sync requirements.txt
```

**Difference:**
- `install -r`: Installs packages, leaves extras
- `sync`: Ensures environment exactly matches file

---

## uv pip sync Explained

### Without sync:

```bash
# Initial state: package-a, package-b installed
uv pip install -r requirements.txt
# requirements.txt only lists package-a
# Result: package-a AND package-b still installed
```

### With sync:

```bash
uv pip sync requirements.txt
# requirements.txt only lists package-a
# Result: package-a installed, package-b REMOVED
```

**sync ensures perfect environment reproduction**

---

## Complete Lock File Workflow

```bash
# 1. Create requirements.in
cat > requirements.in << EOF
uipath>=0.2.0,<1.0.0
python-dotenv>=1.0.0
EOF

# 2. Generate lock file
uv pip compile requirements.in -o requirements.txt

# 3. Install from lock file
uv pip sync requirements.txt

# 4. Commit both files
git add requirements.in requirements.txt
git commit -m "Add dependency lock file"
```

### Update All to Latest Compatible

## Dependency Conflicts

### Example Conflict

```txt
# requirements.in
package-a  # requires httpx>=0.25.0
package-b  # requires httpx<0.24.0
```

**Compile attempt:**
```bash
uv pip compile requirements.in -o requirements.txt
```

**Error:**
```
error: Package 'httpx' has incompatible requirements:
  package-a requires httpx>=0.25.0
  package-b requires httpx<0.24.0
```

---

## Resolving Conflicts

### Strategy 1: Update Packages

```bash
# Try upgrading to latest versions
uv pip compile --upgrade requirements.in -o requirements.txt
```

### Strategy 2: Adjust Constraints

```txt
# requirements.in
package-a
package-b>=2.0.0  # Newer version might support httpx 0.25+
```

### Strategy 3: Find Alternatives

Replace one conflicting package with an alternative

---

## Resolving Conflicts (Continued)

### Strategy 4: Override (Advanced)

```txt
# requirements.in
package-a
package-b

# Force specific version (use cautiously)
httpx==0.24.1
```

**Warning:** May cause runtime issues if forced version is incompatible

## Understanding Transitive Dependencies

### Direct Dependencies

```txt
# requirements.in
uipath
```

### Transitive Dependencies

```txt
# requirements.txt (compiled)
uipath==0.2.0
httpx==0.25.0       # uipath depends on httpx
certifi==2023.7.22  # httpx depends on certifi
...
```

**Transitive = dependencies of dependencies**

## uv Cache Management

### How uv Caching Works

1. Package downloaded → Stored in global cache
2. Future installs → Reuse from cache
3. Across projects → Same packages shared

**Location:**
- macOS/Linux: `~/.cache/uv`
- Windows: `%LOCALAPPDATA%\uv\cache`

---

## uv Cache Commands

```bash
# Clear cache (frees disk space)
uv cache clean

# Show cache directory
uv cache dir

# Show cache statistics
uv cache info
```

**Cache benefits:**
- Faster repeated installations
- Reduced bandwidth usage
- Offline installs (if cached)

## Optimizing Dependency Trees

### Problem: Diamond Dependencies

```
your-app
├── package-a → httpx 0.24.*
└── package-b → httpx 0.25.*
```

**uv resolves to single compatible version**

---

## Optimizing Dependency Trees (Continued)

### Strategies

1. **Minimize direct dependencies**
   - Only include what you actually use

2. **Use compatible version ranges**
   ```txt
   uipath>=0.2.0,<1.0.0  # Allow minor updates
   ```

3. **Regular updates**
   ```bash
   uv pip compile --upgrade requirements.in -o requirements.txt
   ```

4. **Review dependency tree**
   ```bash
   pipdeptree
   ```

## Troubleshooting

### Issue 1: Compilation Fails

**Error:** "Cannot resolve dependencies"

**Solution:**
```bash
# Try with upgrade flag
uv pip compile --upgrade requirements.in -o requirements.txt

# Check for conflicts
pipdeptree
```

---

## Troubleshooting (Continued)

### Issue 2: Slow First Install

**Cause:** Building packages from source

**Solution:**
```bash
# Use wheels (pre-built binaries)
uv pip install --only-binary :all: -r requirements.txt
```

Or wait for cache to populate

---

## Troubleshooting (Continued)

### Issue 3: Environment Mismatch

**Problem:** `pip list` shows packages not in requirements.txt

**Solution:**
```bash
# Use sync instead of install
uv pip sync requirements.txt

# Verifies environment exactly matches file
```
