## What Are Assets?

**Assets store configuration values and credentials centrally in Orchestrator**

**Purpose:**
- Externalize configuration from workflows
- Change values without republishing
- Different values per environment (Dev/Prod)
- Secure credential storage
- Centralized secrets management

**Think of Assets as:** Environment variables + secrets vault for robots

---

## Why Use Assets?

**Without Assets:**
```python
# Hard-coded in workflow
api_url = "https://api.example.com"
db_connection = "Server=prod-db;Database=..."
api_key = "secret123"  # ⚠️ Exposed in workflow!
```

**With Assets:**
```python
# Workflow reads from Orchestrator
api_url = Get Asset "API_URL"
db_connection = Get Asset "DB_Connection"
api_key = Get Credential "API_Key"  # 🔒 Encrypted
```

**Benefits:** Change URLs without republishing, secure secrets, environment-specific config

---

## Asset Types

**Four value types:**

| Type | Purpose | Example |
|------|---------|---------|
| **Text** | Plain text strings | URLs, email addresses, file paths |
| **Bool** | True/False flags | Feature toggles, debug mode |
| **Integer** | Numeric values | Thresholds, retry counts, timeouts |
| **Credential** | Username/password | Database logins, API keys, service accounts |

**Most common:** Text (configuration) and Credential (secrets)

---

## Text Assets

**Store plain text configuration values**

**Examples:**
- API base URLs
- Email addresses
- File paths
- Server names
- Thresholds and limits
- Feature flags (as text: "enabled"/"disabled")

**Important:** Text assets are NOT encrypted

**Rule:** Never store passwords or secrets in Text assets

---

## Credential Assets

**Store username/password pairs securely**

**Characteristics:**
- Password is encrypted
- Username is plain text
- Password never exposed in logs or API responses
- Only robots can decrypt passwords

**Examples:**
- Database credentials
- Application login accounts
- API keys (use dummy username + key as password)
- Service account credentials

**Security:** Passwords are encrypted at rest and in transit

---

## Asset Scope: Global vs Per Robot

**Two scope options:**

**Global:**
- One value shared by all robots
- Most common
- Use for environment-wide configuration

**Per Robot:**
- Different value for each robot
- Less common
- Use for machine-specific settings

---

## Global Scope Example

```
Asset: "API_URL" (Global)
Value: "https://api.production.com"

Robot-01 reads asset → "https://api.production.com"
Robot-02 reads asset → "https://api.production.com"
Robot-03 reads asset → "https://api.production.com"
```

**All robots get the same value**

**Use for:** APIs, databases, email addresses, shared config

---

## Per Robot Scope Example

```
Asset: "LocalFolder" (Per Robot)
Robot-01 value: "C:\Data\Robot01"
Robot-02 value: "C:\Data\Robot02"
Robot-03 value: "D:\RobotData"

Robot-01 reads asset → "C:\Data\Robot01"
Robot-02 reads asset → "C:\Data\Robot02"
Robot-03 reads asset → "D:\RobotData"
```

**Each robot gets its own value**

**Use for:** Local paths, printer names, machine-specific config

---

## Asset Structure

**Each asset has:**

- **Name:** Unique identifier (e.g., "API_URL")
- **Value:** The actual data
- **ValueType:** Text, Bool, Integer, or Credential
- **ValueScope:** Global or PerRobot
- **Description:** Optional documentation
- **Id:** Numeric identifier for API operations

**Assets belong to a folder** (folder context required)

## Getting Assets via API: Overview

**Two main scenarios:**

**1. Get Global Asset**
- Retrieve value that's the same for all robots
- Use: `GetAssetByName` function

**2. Get Per Robot Asset**
- Retrieve value for specific robot
- Use: `GetRobotAssetByName` function
- Requires robot ID

---

## Getting Global Text Asset

**Endpoint:**
```
GET /odata/Assets/UiPath.Server.Configuration.OData.GetAssetByName(assetName='API_URL')
```

**Code example:**
```python
def get_asset(base_url, token, folder_id, asset_name):
    """Get a global asset value"""

    response = requests.get(
        f"{base_url}/odata/Assets/UiPath.Server.Configuration.OData.GetAssetByName(assetName='{asset_name}')",
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id)
        }
    )

    response.raise_for_status()
    asset = response.json()
    return asset['Value']

# Usage
api_url = get_asset(base_url, token, folder_id, 'API_URL')
print(f"API URL: {api_url}")
```

---

## Getting Credential Asset

**Same endpoint, but returns username + encrypted password:**

```python
def get_credential(base_url, token, folder_id, asset_name):
    """Get a credential asset"""

    response = requests.get(
        f"{base_url}/odata/Assets/UiPath.Server.Configuration.OData.GetAssetByName(assetName='{asset_name}')",
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id)
        }
    )

    response.raise_for_status()
    asset = response.json()

    return {
        'username': asset.get('CredentialUsername'),
        'password': asset.get('CredentialPassword')  # ⚠️ Encrypted!
    }

# Note: Password is encrypted string, not plain text
```

---

## Important: Credential Passwords

**The password you get is encrypted:**

```python
credential = get_credential(base_url, token, folder_id, 'DB_Login')

print(credential['username'])  # ✓ Plain text: "sa"
print(credential['password'])  # ⚠️ Encrypted: "Rz4fG7...encrypted..."
```

**You CANNOT decrypt it via API**

**Only robots can decrypt credentials** during workflow execution

**This is intentional security design**

---

## Why Encrypted Passwords?

**Security benefits:**

1. **No password exposure** in logs, scripts, error messages
2. **Prevents credential harvesting** by unauthorized scripts
3. **Audit trail** of credential access
4. **Separation of duties** (admins manage, robots use)

**If you need to programmatically use credentials:**
- Use the robot to perform the action
- Don't try to extract credentials for use in your Python script

## Listing All Assets

**Get all assets in a folder:**

```python
def get_all_assets(base_url, token, folder_id):
    """Get all assets in folder"""

    response = requests.get(
        f'{base_url}/odata/Assets',
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id)
        }
    )

    return response.json()['value']

# Usage
assets = get_all_assets(base_url, token, folder_id)
for asset in assets:
    print(f"{asset['Name']}: {asset['ValueType']} ({asset['ValueScope']})")
```

**Returns:** All assets with full metadata

## Updating Asset Values

**To update an asset value:**

1. Get the asset Id (if you don't have it)
2. PUT/PATCH to `/odata/Assets({id})` with new value

```python
def update_asset(base_url, token, folder_id, asset_name, new_value):
    """Update an asset's value"""

    # 1. Find asset by name to get Id
    assets_response = requests.get(
        f'{base_url}/odata/Assets',
        params={'$filter': f"Name eq '{asset_name}'"},
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id)
        }
    )

    assets = assets_response.json()['value']
    if not assets:
        raise ValueError(f"Asset '{asset_name}' not found")

    asset = assets[0]
    asset_id = asset['Id']

    # 2. Update the value
    asset['Value'] = new_value

    response = requests.put(
        f'{base_url}/odata/Assets({asset_id})',
        json=asset,
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id),
            'Content-Type': 'application/json'
        }
    )

    response.raise_for_status()
    return response.json()
```

---

## Updating with PATCH

**PATCH for partial updates (simpler):**

```python
def update_asset_value(base_url, token, folder_id, asset_id, new_value):
    """Update only the Value field"""

    response = requests.patch(
        f'{base_url}/odata/Assets({asset_id})',
        json={'Value': new_value},
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id),
            'Content-Type': 'application/json'
        }
    )

    response.raise_for_status()
    return response.json()

# Usage
update_asset_value(base_url, token, folder_id, asset_id=123, new_value='https://api.newurl.com')
```

**PATCH sends only changed fields** (more efficient than PUT)

## Creating Assets

**Create a new asset:**

```python
def create_asset(base_url, token, folder_id, name, value, value_type='Text', scope='Global'):
    """Create a new asset"""

    payload = {
        'Name': name,
        'ValueType': value_type,  # Text, Bool, Integer, Credential
        'ValueScope': scope,      # Global or PerRobot
        'Value': value if value_type != 'Credential' else None,
        'CredentialUsername': None,
        'CredentialPassword': None,
        'Description': ''
    }

    # For credentials, set username and password
    if value_type == 'Credential':
        payload['CredentialUsername'] = value['username']
        payload['CredentialPassword'] = value['password']
        del payload['Value']

    response = requests.post(
        f'{base_url}/odata/Assets',
        json=payload,
        headers={
            'Authorization': f'Bearer {token}',
            'X-UIPATH-OrganizationUnitId': str(folder_id),
            'Content-Type': 'application/json'
        }
    )

    response.raise_for_status()
    return response.json()
```

## Security Best Practices

**1. Use Credential assets for secrets**
```python
# ✅ Good: API key as credential
create_asset(name='API_Key', value={'username': 'api_key', 'password': 'secret123'}, value_type='Credential')

# ❌ Bad: API key as text
create_asset(name='API_Key', value='secret123', value_type='Text')
```

**2. Never log credential values**
```python
# ❌ Bad
print(f"Using password: {credential['password']}")  # Even if encrypted, don't log

# ✅ Good
print("Retrieved credential successfully")
```

**3. Rotate credentials regularly**

**4. Use least privilege** (limit who can read/update assets)

## Environment Configuration Strategy

**Best practice: Same asset names, different values per environment**

```
Development Folder:
  Asset "API_URL" = "https://api.dev.example.com"
  Asset "DB_Connection" = "Server=dev-db..."

Production Folder:
  Asset "API_URL" = "https://api.prod.example.com"
  Asset "DB_Connection" = "Server=prod-db..."
```

**Your workflow reads "API_URL"**—gets different value based on which folder it runs in

**Deploy same workflow to all environments** without changes

**Good naming practices:**

- Descriptive names
- Group related assets with prefixes (API_, DB_, Email_)

## Common Pattern: Configuration Class

```python
class Config:
    """Load all configuration from Orchestrator assets"""

    def __init__(self, base_url, token, folder_id):
        self.base_url = base_url
        self.token = token
        self.folder_id = folder_id
        self._cache = {}

    def get(self, asset_name):
        """Get asset with caching"""
        if asset_name not in self._cache:
            self._cache[asset_name] = self._fetch_asset(asset_name)
        return self._cache[asset_name]

    def _fetch_asset(self, asset_name):
        response = requests.get(
            f"{self.base_url}/odata/Assets/UiPath.Server.Configuration.OData.GetAssetByName(assetName='{asset_name}')",
            headers={
                'Authorization': f'Bearer {self.token}',
                'X-UIPATH-OrganizationUnitId': str(self.folder_id)
            }
        )
        response.raise_for_status()
        return response.json()['Value']

# Usage
config = Config(base_url, token, folder_id)
api_url = config.get('API_URL')
max_retries = int(config.get('MaxRetries'))
```

## Common Pattern: Bulk Asset Update

```python
def bulk_update_assets(base_url, token, folder_id, updates):
    """Update multiple assets at once"""

    # updates = {'API_URL': 'new_url', 'MaxRetries': '5', ...}

    for asset_name, new_value in updates.items():
        try:
            # Get asset
            assets = requests.get(
                f'{base_url}/odata/Assets',
                params={'$filter': f"Name eq '{asset_name}'"},
                headers={
                    'Authorization': f'Bearer {token}',
                    'X-UIPATH-OrganizationUnitId': str(folder_id)
                }
            ).json()['value']

            if assets:
                asset_id = assets[0]['Id']
                # Update
                requests.patch(
                    f'{base_url}/odata/Assets({asset_id})',
                    json={'Value': new_value},
                    headers={
                        'Authorization': f'Bearer {token}',
                        'X-UIPATH-OrganizationUnitId': str(folder_id),
                        'Content-Type': 'application/json'
                    }
                ).raise_for_status()
                print(f"✓ Updated {asset_name}")
            else:
                print(f"✗ Asset {asset_name} not found")

        except Exception as e:
            print(f"✗ Error updating {asset_name}: {e}")
```

## Common Pattern: Environment Migration

```python
def copy_assets_to_folder(source_folder_id, target_folder_id):
    """Copy all assets from one folder to another"""

    # Get all assets from source
    source_assets = get_all_assets(base_url, token, source_folder_id)

    for asset in source_assets:
        # Create in target folder
        create_asset(
            base_url, token, target_folder_id,
            name=asset['Name'],
            value=asset['Value'],
            value_type=asset['ValueType'],
            scope=asset['ValueScope']
        )
        print(f"✓ Copied {asset['Name']}")

# Usage: Copy Dev assets to Staging
copy_assets_to_folder(dev_folder_id, staging_folder_id)
```

**Note:** Credential passwords won't copy—you'll need to reset them

## Troubleshooting

**Asset not found:**
- Check folder context (X-UIPATH-OrganizationUnitId header)
- Verify asset name (case-sensitive)
- Ensure asset exists in that folder

**Can't update asset:**
- Check permissions (need Edit permission on folder)
- Verify asset Id is correct
- Ensure payload is valid JSON

**Credential password is encrypted:**
- This is normal and expected
- Don't try to decrypt it
- Use robots to work with credentials

## Asset Limits

**Be aware of:**

- **Asset name length:** Max 100 characters
- **Value length:** Text assets max 5,000 characters for Global, 450 for Per Robot
- **Number of assets:** No hard limit, but keep organized
- **API rate limits:** Don't fetch assets excessively; cache values

**Recommendation:** Cache asset values in your script; don't fetch on every use
