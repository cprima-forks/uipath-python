## Why Async Programming?

**The Problem:**
- Agents often wait for I/O operations
- Network requests
- File operations
- Database queries
- API calls

**Without async**: Your agent sits idle, wasting time

**With async**: While waiting, your agent can do other work

---

## The Restaurant Analogy

**Synchronous (Traditional):**
- Waiter takes order from table 1
- Waiter waits at kitchen until food is ready
- Waiter delivers food
- Only then goes to table 2

**Asynchronous:**
- Waiter takes order from table 1
- While kitchen cooks, waiter serves tables 2, 3, 4
- When food is ready, waiter delivers it
- Multiple tasks progress concurrently

---

## Concurrency vs Parallelism

```
Concurrency (Async):
Task A: ===wait===...===wait===...done
Task B: ...===wait===...===wait===...done
        [Single thread switches between tasks]

Parallelism (Multi-core):
Task A: ========================done
Task B: ========================done
        [Multiple threads/processes simultaneously]
```

**Async = Concurrency, not parallelism**

Python's async is single-threaded but handles multiple tasks

---

## Synchronous Code Example

```python
import time

def fetch_data(name):
    print(f"Fetching {name}...")
    time.sleep(2)  # Simulates network delay
    print(f"Got {name}")
    return f"Data from {name}"

# Sequential execution
start = time.time()
data1 = fetch_data("API-1")
data2 = fetch_data("API-2")
data3 = fetch_data("API-3")
print(f"Total time: {time.time() - start:.2f}s")

# Output: Total time: 6.00s
```

**Problem**: Each call blocks until complete

---

## Asynchronous Code Example

```python
import asyncio

async def fetch_data(name):
    print(f"Fetching {name}...")
    await asyncio.sleep(2)  # Simulates network delay
    print(f"Got {name}")
    return f"Data from {name}"

async def main():
    start = time.time()
    # Run concurrently
    results = await asyncio.gather(
        fetch_data("API-1"),
        fetch_data("API-2"),
        fetch_data("API-3")
    )
    print(f"Total time: {time.time() - start:.2f}s")

asyncio.run(main())

# Output: Total time: 2.00s
```

**3x faster** by running concurrently!

## What is a Coroutine?

A **coroutine** is a special function that can pause and resume

```python
# Regular function
def regular_function():
    return 42

# Coroutine (async function)
async def coroutine_function():
    return 42
```

**Key differences:**
- Defined with `async def`
- Can use `await` inside
- Returns a coroutine object when called
- Must be awaited or run by event loop

---

## Defining Coroutines

```python
# Coroutine definition
async def process_document(doc_id):
    """Process a document asynchronously."""
    print(f"Starting to process {doc_id}")

    # Simulate async operation
    await asyncio.sleep(1)

    result = f"Processed {doc_id}"
    print(f"Finished processing {doc_id}")
    return result

# Calling a coroutine
coro = process_document("doc_123")
print(type(coro))  # <class 'coroutine'>

# Must await it or run it
result = await process_document("doc_123")  # Inside async function
# OR
result = asyncio.run(process_document("doc_123"))  # From sync code
```

---

## Common Mistake: Forgetting Await

```python
async def get_value():
    await asyncio.sleep(1)
    return 42

async def main():
    # ❌ WRONG: Forgot await
    result = get_value()
    print(result)  # <coroutine object>

    # ✅ CORRECT: Use await
    result = await get_value()
    print(result)  # 42

asyncio.run(main())
```

**Warning**: `coroutine was never awaited`

This means you called an async function but didn't await it!

---

## The Await Keyword

**`await` does three things:**

1. **Suspends** the current coroutine
2. **Yields control** back to the event loop
3. **Resumes** when the awaited operation completes

```python
async def example():
    print("Before await")
    result = await some_async_operation()
    print("After await")  # Resumes here when done
    return result
```

**You can only use `await` inside `async` functions**

---

## What Can You Await?

```python
# ✅ Can await:
await coroutine_function()      # Coroutines
await asyncio.sleep(1)          # Async functions
await asyncio.gather(...)       # Asyncio utilities

# ❌ Cannot await:
await regular_function()        # Regular functions
await 42                        # Regular values
await time.sleep(1)             # Sync functions
```

**Only awaitable objects can be awaited:**
- Coroutines
- Tasks
- Futures
- Objects with `__await__` method

## The Event Loop

The **event loop** is the engine that runs async code

```python
┌─────────────────────────────────┐
│       Event Loop                │
│                                 │
│  ┌──────┐  ┌──────┐  ┌──────┐ │
│  │Task 1│  │Task 2│  │Task 3│ │
│  └──────┘  └──────┘  └──────┘ │
│                                 │
│  Schedules, switches, resumes  │
└─────────────────────────────────┘
```

**Event loop responsibilities:**
- Schedule coroutines
- Switch between them at await points
- Handle I/O operations
- Manage callbacks

---

## Event Loop Execution Flow

```python
async def task1():
    print("Task 1: Start")
    await asyncio.sleep(0)  # Yield control
    print("Task 1: End")

async def task2():
    print("Task 2: Start")
    await asyncio.sleep(0)  # Yield control
    print("Task 2: End")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
```

**Output:**
```
Task 1: Start
Task 2: Start
Task 1: End
Task 2: End
```

**Both tasks start, then interleave at await points**

## Running Async Code: asyncio.run()

```python
import asyncio

async def my_agent():
    print("Agent starting...")
    await asyncio.sleep(1)
    print("Agent completed!")
    return "Success"

# Entry point from synchronous code
result = asyncio.run(my_agent())
print(result)  # "Success"
```

**`asyncio.run()`:**
- Creates a new event loop
- Runs the coroutine
- Closes the loop when done
- **Can only be called once per program**

---

## Running Multiple Coroutines: asyncio.gather()

```python
async def fetch_user(user_id):
    await asyncio.sleep(1)
    return f"User {user_id}"

async def fetch_orders(user_id):
    await asyncio.sleep(1)
    return f"Orders for {user_id}"

async def main():
    # Run concurrently and wait for all
    user, orders = await asyncio.gather(
        fetch_user(123),
        fetch_orders(123)
    )
    print(user)    # User 123
    print(orders)  # Orders for 123

asyncio.run(main())
```

**`asyncio.gather()`** runs multiple coroutines concurrently

Returns results in order when all complete

---

## Running Multiple Coroutines: asyncio.create_task()

```python
async def process_document(doc_id):
    await asyncio.sleep(2)
    return f"Processed {doc_id}"

async def main():
    # Create tasks (start immediately)
    task1 = asyncio.create_task(process_document("doc1"))
    task2 = asyncio.create_task(process_document("doc2"))

    # Do other work here...
    print("Tasks running in background...")

    # Wait for results
    result1 = await task1
    result2 = await task2

    print(result1, result2)

asyncio.run(main())
```

**Tasks start executing immediately when created**

## Async vs Sync: When to Use Each

**Use Async For:**
- ✅ Network requests (HTTP, API calls)
- ✅ File I/O operations
- ✅ Database queries
- ✅ Multiple concurrent operations
- ✅ I/O-bound workloads

**Use Sync For:**
- ✅ CPU-intensive calculations
- ✅ Simple scripts
- ✅ Short-running operations
- ✅ When no I/O waiting occurs

---

## Blocking vs Non-Blocking

```python
# ❌ BAD: Blocks the event loop
async def bad_example():
    time.sleep(2)  # Synchronous! Blocks everything
    return "Done"

# ✅ GOOD: Non-blocking
async def good_example():
    await asyncio.sleep(2)  # Async! Yields control
    return "Done"
```

**Critical rule**: Never use synchronous blocking operations in async code

- Don't use `time.sleep()` → Use `await asyncio.sleep()`
- Don't use `requests` → Use `aiohttp`
- Don't use `open()` → Use `aiofiles`

## Async Libraries

**Must use async-compatible libraries:**

```python
# Synchronous (blocking)        # Asynchronous (non-blocking)
import requests                 import aiohttp
import open                     import aiofiles
import psycopg2                 import asyncpg
import redis                    import aioredis
```

**Why?** Synchronous libraries block the event loop, preventing concurrency

**Async libraries** use `await` for I/O, allowing other tasks to run

## Example: Async HTTP Requests

```python
import aiohttp
import asyncio

async def fetch_url(session, url):
    async with session.get(url) as response:
        return await response.text()

async def main():
    urls = [
        "https://api.example.com/users",
        "https://api.example.com/products",
        "https://api.example.com/orders"
    ]

    async with aiohttp.ClientSession() as session:
        tasks = [fetch_url(session, url) for url in urls]
        results = await asyncio.gather(*tasks)

    print(f"Fetched {len(results)} URLs concurrently")

asyncio.run(main())
```

**All requests run concurrently**

## Async Context Managers

```python
# Synchronous context manager
with open("file.txt") as f:
    data = f.read()

# Asynchronous context manager
async with aiofiles.open("file.txt") as f:
    data = await f.read()
```

**Use `async with` for async context managers**

Common with:
- File operations (`aiofiles`)
- Network connections (`aiohttp`)
- Database connections (`asyncpg`)

## Async Iterators

```python
async def fetch_pages():
    """Async generator."""
    for page in range(1, 6):
        await asyncio.sleep(0.5)
        yield f"Page {page}"

async def main():
    # Use 'async for' to iterate
    async for page in fetch_pages():
        print(page)

asyncio.run(main())
```

**Use `async for` with async iterators**

Useful for streaming data, paginated APIs, etc.

## Real-World Example: Document Processing Agent

```python
async def process_document(doc_path):
    """Process a document asynchronously."""
    async with aiofiles.open(doc_path) as f:
        content = await f.read()

    # Simulate processing
    await asyncio.sleep(1)

    return len(content)

async def process_batch(doc_paths):
    """Process multiple documents concurrently."""
    tasks = [process_document(path) for path in doc_paths]
    results = await asyncio.gather(*tasks)

    total_chars = sum(results)
    print(f"Processed {len(results)} documents")
    print(f"Total characters: {total_chars}")

# Usage
documents = ["doc1.txt", "doc2.txt", "doc3.txt"]
asyncio.run(process_batch(documents))
```

## Real-World Example: API Agent

```python
import aiohttp

async def call_api(session, endpoint):
    """Call UiPath API endpoint."""
    url = f"https://cloud.uipath.com/api/{endpoint}"

    async with session.get(url, headers=headers) as response:
        if response.status == 200:
            return await response.json()
        else:
            raise Exception(f"API error: {response.status}")

async def fetch_agent_data(agent_ids):
    """Fetch data for multiple agents concurrently."""
    async with aiohttp.ClientSession() as session:
        tasks = [
            call_api(session, f"agents/{agent_id}")
            for agent_id in agent_ids
        ]

        results = await asyncio.gather(*tasks, return_exceptions=True)

    # Filter successful results
    return [r for r in results if not isinstance(r, Exception)]
```

## Common Pitfall 1: Calling Without Await

```python
async def get_data():
    await asyncio.sleep(1)
    return "data"

async def main():
    # ❌ WRONG: Creates coroutine but doesn't run it
    result = get_data()
    print(result)  # <coroutine object>

    # ✅ CORRECT: Await the coroutine
    result = await get_data()
    print(result)  # "data"
```

**Warning**: `RuntimeWarning: coroutine was never awaited`

---

## Common Pitfall 2: Blocking the Event Loop

```python
import time

# ❌ WRONG: Blocks event loop
async def bad_sleep():
    time.sleep(5)  # Everything stops for 5 seconds!

# ✅ CORRECT: Non-blocking sleep
async def good_sleep():
    await asyncio.sleep(5)  # Other tasks can run
```

**Rule**: Never use blocking operations in async functions

Use async equivalents:
- `await asyncio.sleep()` not `time.sleep()`
- `aiohttp` not `requests`
- `aiofiles` not `open()`

---

## Common Pitfall 3: Multiple asyncio.run() Calls

```python
# ❌ WRONG: Can't call asyncio.run() multiple times
async def task1():
    return "Result 1"

async def task2():
    return "Result 2"

result1 = asyncio.run(task1())  # OK
result2 = asyncio.run(task2())  # ERROR!
```

**Solution**: Create one main() function

```python
# ✅ CORRECT: Single entry point
async def main():
    result1 = await task1()
    result2 = await task2()
    return result1, result2

asyncio.run(main())
```

---

## Common Pitfall 4: Not Handling Exceptions

```python
# ❌ WRONG: Exception in one task stops everything
async def main():
    results = await asyncio.gather(
        risky_task1(),
        risky_task2(),
        risky_task3()
    )

# ✅ CORRECT: Handle exceptions gracefully
async def main():
    results = await asyncio.gather(
        risky_task1(),
        risky_task2(),
        risky_task3(),
        return_exceptions=True  # Returns exceptions instead of raising
    )

    for result in results:
        if isinstance(result, Exception):
            print(f"Task failed: {result}")
```

## Performance Considerations

**Async is NOT always faster:**

```python
# CPU-bound: Async adds overhead, no benefit
async def calculate():
    return sum(range(1_000_000))  # Pure computation

# I/O-bound: Async provides huge benefit
async def fetch_data():
    await asyncio.sleep(1)  # Waiting for network
    return data
```

**When async helps:**
- Many I/O operations
- Network requests
- File operations
- Waiting for external resources

**When async doesn't help:**
- CPU-intensive calculations
- No waiting/blocking
- Single operation

## Best Practices Summary

**DO:**
- ✅ Use `async def` to define coroutines
- ✅ Use `await` to call coroutines
- ✅ Use `asyncio.run()` as entry point
- ✅ Use `asyncio.gather()` for concurrent execution
- ✅ Use async libraries (aiohttp, aiofiles, asyncpg)
- ✅ Use `async with` and `async for`
- ✅ Handle exceptions with `return_exceptions=True`

**DON'T:**
- ❌ Forget to await coroutines
- ❌ Use blocking operations (time.sleep, requests)
- ❌ Call asyncio.run() multiple times
- ❌ Mix sync and async code carelessly

## Async/Await Cheat Sheet

```python
# Define coroutine
async def my_coroutine():
    pass

# Call from sync code
asyncio.run(my_coroutine())

# Call from async code
await my_coroutine()

# Run multiple concurrently
await asyncio.gather(coro1(), coro2(), coro3())

# Create background task
task = asyncio.create_task(my_coroutine())

# Async context manager
async with resource:
    pass

# Async iterator
async for item in async_generator():
    pass
```
