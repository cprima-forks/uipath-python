## The Configuration Problem

**Agents need different settings for different environments:**

```python
# ❌ BAD: Hard-coded secrets in code
API_KEY = "sk-prod-abc123xyz789"
DATABASE_URL = "postgres://prod-server/db"
DEBUG = False
```

**Problems:**
- Secrets exposed in source code
- Can't change config without changing code
- Same code can't run in dev and prod
- Security nightmare if committed to git

---

## The Solution: Environment Variables

**Store configuration outside your code:**

```python
# ✅ GOOD: Load from environment
import os

API_KEY = os.getenv("API_KEY")
DATABASE_URL = os.getenv("DATABASE_URL")
DEBUG = os.getenv("DEBUG", "False") == "True"
```

**Benefits:**
- Secrets stay out of source code
- Easy to change without code changes
- Different values for dev/staging/prod
- Follows 12-factor app principles

## What are Environment Variables?

**Key-value pairs set in the operating system:**

```bash
# Linux/Mac
export API_KEY="secret123"
export DATABASE_URL="postgres://localhost/mydb"

# Windows
set API_KEY=secret123
set DATABASE_URL=postgres://localhost/mydb
```

**Accessed in Python:**
```python
import os
api_key = os.getenv("API_KEY")
```

**But setting them manually is tedious...**

---

## Enter .env Files

**A file that stores environment variables:**

```
# .env
API_KEY=secret123
DATABASE_URL=postgres://localhost/mydb
DEBUG=True
MAX_RETRIES=3
TIMEOUT=30
```

**Load automatically with python-dotenv:**
```python
from dotenv import load_dotenv
import os

load_dotenv()  # Loads .env into environment

api_key = os.getenv("API_KEY")
```

**Much easier than setting variables manually!**

## Creating a .env File

**Simple KEY=value format:**

```
# .env
# API Configuration
API_KEY=sk-test-abc123
API_BASE_URL=https://api.example.com

# Database
DATABASE_URL=postgresql://user:pass@localhost:5432/mydb
DATABASE_POOL_SIZE=10

# Application Settings
DEBUG=True
LOG_LEVEL=INFO
MAX_WORKERS=4

# UiPath Settings
ORCHESTRATOR_URL=https://cloud.uipath.com
ORCHESTRATOR_TENANT=MyTenant
```

**No quotes needed (unless value has spaces)**

---

## .env File Syntax Rules

```
# Comments start with #
API_KEY=value123

# No spaces around = (though they work)
DATABASE_URL=postgres://localhost/db

# Quotes optional for simple values
NAME=value
NAME="value"  # Same result

# Quotes required for spaces
MESSAGE="Hello World"

# Multiline values (advanced)
PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----
MIIEpAIBAAKCAQEA...
-----END RSA PRIVATE KEY-----"

# No variable expansion by default
HOME_DIR=/home/user
LOG_DIR=$HOME_DIR/logs  # $HOME_DIR not expanded!
```

## Loading .env Files

**Basic usage:**
```python
from dotenv import load_dotenv
import os

# Load .env from current directory
load_dotenv()

# Access variables
api_key = os.getenv("API_KEY")
database_url = os.getenv("DATABASE_URL")
```

**Specify file location:**
```python
# Load from specific path
load_dotenv("/path/to/.env")

# Load from parent directory
load_dotenv("../.env")

# Load from project root
from pathlib import Path
env_path = Path(".") / ".env"
load_dotenv(dotenv_path=env_path)
```

## Default Values and Type Conversion

**Provide defaults if variable not set:**
```python
import os

# With default
debug = os.getenv("DEBUG", "False")
max_retries = int(os.getenv("MAX_RETRIES", "3"))
timeout = float(os.getenv("TIMEOUT", "30.0"))

# Convert to boolean
debug_bool = os.getenv("DEBUG", "False").lower() == "true"
```

**Helper function for booleans:**
```python
def get_bool(key, default=False):
    value = os.getenv(key, str(default))
    return value.lower() in ("true", "1", "yes", "on")

DEBUG = get_bool("DEBUG")
ENABLE_CACHE = get_bool("ENABLE_CACHE", True)
```

## Override Behavior

**By default, existing environment variables are NOT overwritten:**

```python
# System has API_KEY=system-value set

# .env file has:
# API_KEY=dotenv-value

load_dotenv()  # Does not override
api_key = os.getenv("API_KEY")
# Result: "system-value" (system wins)

# Force override
load_dotenv(override=True)
api_key = os.getenv("API_KEY")
# Result: "dotenv-value" (.env wins)
```

**This allows system-level config to take precedence**

## Security Best Practices

**❌ NEVER commit .env to version control:**

```
# .gitignore
.env
.env.local
.env.*.local
*.env
```

**✅ DO commit .env.example as a template:**

```
# .env.example
API_KEY=your-api-key-here
DATABASE_URL=postgresql://user:pass@localhost:5432/dbname
DEBUG=False
```

**Team members copy .env.example to .env and fill in real values**

---

## Why .env Files Shouldn't Be Committed

**If you commit .env to git:**
- 🔓 Secrets exposed in git history (forever!)
- 🔓 Public repos = public secrets
- 🔓 Anyone with repo access sees production keys
- 🔓 Hard to rotate credentials (must change code)
- 🔓 CI/CD systems may log secrets

**Keep secrets OUT of version control!**

## Managing Multiple Environments

**Separate .env files for each environment:**

```
.env.development
.env.staging
.env.production
```

**Load based on environment:**
```python
import os
from dotenv import load_dotenv

# Get environment from ENV variable (or default to dev)
env = os.getenv("ENVIRONMENT", "development")

# Load appropriate .env file
load_dotenv(f".env.{env}")

# Now use your config
api_key = os.getenv("API_KEY")
```

## Configuration Class Pattern

**Organize config in a class:**

```python
import os
from dotenv import load_dotenv

load_dotenv()

class Config:
    # API Settings
    API_KEY = os.getenv("API_KEY")
    API_BASE_URL = os.getenv("API_BASE_URL", "https://api.example.com")

    # Database
    DATABASE_URL = os.getenv("DATABASE_URL")
    DATABASE_POOL_SIZE = int(os.getenv("DATABASE_POOL_SIZE", "10"))

    # Application
    DEBUG = os.getenv("DEBUG", "False").lower() == "true"
    LOG_LEVEL = os.getenv("LOG_LEVEL", "INFO")
    MAX_WORKERS = int(os.getenv("MAX_WORKERS", "4"))

# Usage
if Config.DEBUG:
    print(f"Connecting to {Config.DATABASE_URL}")
```

## Validating Required Variables

**Fail fast if required config is missing:**

```python
from dotenv import load_dotenv
import os
import sys

load_dotenv()

# Required variables
REQUIRED = [
    "API_KEY",
    "DATABASE_URL",
    "ORCHESTRATOR_URL"
]

# Check all required variables exist
missing = [var for var in REQUIRED if not os.getenv(var)]

if missing:
    print(f"Error: Missing required environment variables: {', '.join(missing)}")
    print("Please check your .env file")
    sys.exit(1)

# Safe to proceed
api_key = os.getenv("API_KEY")
```

## Pydantic for Configuration

**Type-safe configuration with validation:**

```python
from pydantic import BaseSettings, Field

class Settings(BaseSettings):
    api_key: str = Field(..., env="API_KEY")
    database_url: str = Field(..., env="DATABASE_URL")
    debug: bool = Field(False, env="DEBUG")
    max_retries: int = Field(3, env="MAX_RETRIES")
    timeout: float = Field(30.0, env="TIMEOUT")

    class Config:
        env_file = ".env"

# Loads and validates .env automatically
settings = Settings()

# Type-safe access
print(settings.api_key)  # str
print(settings.debug)    # bool
```

**Automatic type conversion and validation!**

## Real-World Example: UiPath Agent Config

```python
# config.py
import os
from dotenv import load_dotenv

load_dotenv()

class AgentConfig:
    # UiPath Orchestrator
    ORCHESTRATOR_URL = os.getenv("ORCHESTRATOR_URL")
    ORCHESTRATOR_TENANT = os.getenv("ORCHESTRATOR_TENANT")
    ORCHESTRATOR_API_KEY = os.getenv("ORCHESTRATOR_API_KEY")

    # Agent Settings
    AGENT_NAME = os.getenv("AGENT_NAME", "MyAgent")
    AGENT_VERSION = os.getenv("AGENT_VERSION", "1.0.0")
    AGENT_DESCRIPTION = os.getenv("AGENT_DESCRIPTION", "")

    # Processing Settings
    MAX_CONCURRENT_TASKS = int(os.getenv("MAX_CONCURRENT_TASKS", "5"))
    TASK_TIMEOUT = int(os.getenv("TASK_TIMEOUT", "300"))

    # Logging
    LOG_LEVEL = os.getenv("LOG_LEVEL", "INFO")
    LOG_FILE = os.getenv("LOG_FILE", "agent.log")
```

## Using the Configuration

```python
from config import AgentConfig
import logging

# Setup logging
logging.basicConfig(
    level=getattr(logging, AgentConfig.LOG_LEVEL),
    filename=AgentConfig.LOG_FILE
)

# Use configuration
async def initialize_agent():
    client = UiPathClient(
        url=AgentConfig.ORCHESTRATOR_URL,
        tenant=AgentConfig.ORCHESTRATOR_TENANT,
        api_key=AgentConfig.ORCHESTRATOR_API_KEY
    )

    agent = Agent(
        name=AgentConfig.AGENT_NAME,
        version=AgentConfig.AGENT_VERSION,
        max_concurrent=AgentConfig.MAX_CONCURRENT_TASKS
    )

    return agent
```

## Common Pitfalls

**Pitfall 1: Committing .env**
```bash
# ❌ Don't do this!
git add .env
```

**Pitfall 2: Using .env in production**
```python
# ❌ In production, set real environment variables
# Don't rely on .env files on servers
```

**Pitfall 3: No validation**
```python
# ❌ Crashes later with cryptic error
api_key = os.getenv("API_KEY")
response = api_client.get(api_key)  # None!

# ✅ Validate at startup
if not os.getenv("API_KEY"):
    raise ValueError("API_KEY required")
```

## Best Practices Summary

**DO:**
- ✅ Use .env files for development
- ✅ Add .env to .gitignore
- ✅ Commit .env.example as template
- ✅ Validate required variables at startup
- ✅ Use separate files per environment
- ✅ Provide sensible defaults
- ✅ Document all variables in .env.example

**DON'T:**
- ❌ Commit .env to version control
- ❌ Use defaults for secrets
- ❌ Hard-code sensitive data
- ❌ Forget to load .env in tests

---

## Deployment Strategies

**Development:**
- Use .env.development locally
- Load with load_dotenv()

**CI/CD:**
- Set environment variables in CI system
- Or use encrypted secret management

**Production:**
- Use platform environment variables (Heroku, AWS, Azure)
- Or secret management systems (AWS Secrets Manager, HashiCorp Vault)
- Don't deploy .env files to servers
