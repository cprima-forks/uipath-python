## What is a Variable?

A **variable** is a named container that stores data

Think of it as a **labeled box** that holds information

```python
agent_name = "DocumentProcessor"
confidence_score = 0.95
is_active = True
```

**Variables let you:**
- Store data for later use
- Give meaningful names to values
- Update and manipulate data
- Build complex programs

---

## Creating Variables

```python
# Variable assignment
message = "Hello, UiPath!"
count = 42
price = 19.99

# Multiple assignment
x, y, z = 10, 20, 30

# Same value to multiple variables
a = b = c = 0
```

**Key points:**
- Use `=` to assign values
- No need to declare type
- Python infers the type automatically
- Can reassign variables to different values

## Variable Naming Rules

**Must follow these rules:**
```python
# ✅ Valid names
user_name = "Alice"
_private = "secret"
count2 = 10
MAX_SIZE = 100

# ❌ Invalid names
2nd_user = "Bob"      # Can't start with number
user-name = "Carol"   # No hyphens
user name = "Dave"    # No spaces
class = "Python"      # Can't use keywords
```

**Rules:**
1. Start with letter or underscore
2. Contain only letters, numbers, underscores
3. Case-sensitive (`name` ≠ `Name`)
4. No Python keywords

---

## Naming Conventions (PEP 8)

```python
# ✅ Variables and functions: snake_case
user_age = 25
total_count = 100
calculate_score()

# ✅ Constants: SCREAMING_SNAKE_CASE
MAX_RETRIES = 3
API_TIMEOUT = 30
DEFAULT_MODEL = "gpt-4"

# ✅ Classes: PascalCase
class DocumentAgent:
    pass

# ❌ Avoid
userName = "bad"      # camelCase (not Pythonic)
Totalcount = "bad"    # Inconsistent
x = "unclear"         # Not descriptive
```

## Choosing Good Variable Names

```python
# ❌ BAD: Unclear, abbreviated
x = 25
usr = "Alice"
tmp = calculate()

# ✅ GOOD: Clear, descriptive
age = 25
user_name = "Alice"
confidence_score = calculate()

# ✅ EVEN BETTER: Contextual
agent_temperature = 0.7
max_retry_attempts = 3
document_processing_timeout = 60
```

**Best practices:**
- Use descriptive names
- Avoid single letters (except in loops)
- Be specific and clear
- Use full words over abbreviations

## Python's Four Primitive Data Types

```python
# 1. Integer (int) - Whole numbers
age = 30
count = -5
population = 1_000_000  # Underscores for readability

# 2. Float (float) - Decimal numbers
temperature = 98.6
pi = 3.14159
stock_price = 125.50

# 3. String (str) - Text
name = "Alice"
message = 'Hello, World!'
description = """Multi-line
string example"""

# 4. Boolean (bool) - True/False
is_active = True
has_error = False
```

---

## Integers (int)

```python
# Whole numbers, positive or negative
count = 42
negative = -17
large_number = 1_000_000_000

# Integer operations
sum_value = 10 + 5      # 15
difference = 10 - 3     # 7
product = 10 * 4        # 40
quotient = 10 // 3      # 3 (floor division)
remainder = 10 % 3      # 1 (modulo)
power = 2 ** 8          # 256

# No size limit in Python 3!
huge = 123456789012345678901234567890
```

---

## Floats (float)

```python
# Decimal numbers
price = 19.99
temperature = -40.5
scientific = 1.5e-10  # Scientific notation

# Float operations
result = 10.0 / 3.0   # 3.3333333333333335
rounded = round(result, 2)  # 3.33

# Watch out for floating-point precision
print(0.1 + 0.2)      # 0.30000000000000004
```

**Important:** Floats have limited precision
- Use `decimal` module for exact decimal math
- Use `round()` for display purposes

## Strings (str)

```python
# Text in quotes (single or double)
name = "Alice"
message = 'Hello, World!'

# String operations
greeting = "Hello" + " " + "World"  # Concatenation
```

## String Formatting

```python
# f-strings (recommended, Python 3.6+)
name = "Alice"
age = 30
message = f"My name is {name} and I am {age} years old"

# Format with expressions
score = 0.856
formatted = f"Confidence: {score:.2%}"  # "Confidence: 85.60%"

# .format() method (older style)
template = "Name: {}, Age: {}".format(name, age)

# % formatting (oldest, avoid)
old_style = "Name: %s, Age: %d" % (name, age)
```

**Use f-strings** - they're fast, readable, and concise!

## Booleans (bool)

```python
# Only two values: True and False
is_active = True
has_error = False

# Boolean operations
and_result = True and False   # False
or_result = True or False     # True
not_result = not True         # False

# Comparison creates booleans
is_greater = 10 > 5          # True
is_equal = 10 == 5           # False
is_not_equal = 10 != 5       # True

# Useful in conditions
if is_active:
    print("Agent is running")
```

## Truthy and Falsy Values

```python
# Falsy values (evaluate to False)

bool(None)        # False

# Truthy values (everything else)

bool("text")      # True
bool([1, 2, 3])   # True

# Practical use

    print("Please provide a name")
```

## Checking Types

```python
# type() function returns the type
age = 25
print(type(age))           # <class 'int'>

name = "Alice"
print(type(name))          # <class 'str'>

score = 98.6
print(type(score))         # <class 'float'>

active = True
print(type(active))        # <class 'bool'>

# isinstance() checks if value is of a type
if isinstance(age, int):
    print("age is an integer")

if isinstance(name, (str, int)):
    print("name is either string or int")
```

## Type Conversion (Casting)

```python
# Converting between types
age_str = "25"
age_int = int(age_str)         # String to integer
age_float = float(age_str)     # String to float

price = 19.99
price_int = int(price)         # 19 (truncates decimal)
price_str = str(price)         # "19.99"

# Boolean conversions
bool(1)                        # True
bool(0)                        # False
int(True)                      # 1
int(False)                     # 0

# Watch out for conversion errors
# int("hello")                 # ValueError!
```

---

## Safe Type Conversion

```python
# Handle conversion errors gracefully
user_input = "123"

try:
    value = int(user_input)
    print(f"Converted value: {value}")
except ValueError:
    print("Could not convert to integer")

# Check before converting
if user_input.isdigit():
    value = int(user_input)
else:
    print("Not a valid number")

# Provide default values
value = int(user_input) if user_input.isdigit() else 0
```

## Real-World Example: Data Validation

```python
# Validating user input for an agent
def validate_confidence_score(score_input):
    """Validate and convert confidence score."""

    # Check if input is a number
    try:
        score = float(score_input)
    except ValueError:
        return False, "Score must be a number"

    # Check range
    if not (0.0 <= score <= 1.0):
        return False, "Score must be between 0 and 1"

    return True, score

# Usage
user_input = "0.95"
is_valid, result = validate_confidence_score(user_input)

if is_valid:
    confidence_score = result
    print(f"Valid score: {confidence_score:.2%}")
else:
    print(f"Error: {result}")
```

## Common Pitfalls

```python
# ❌ Pitfall 1: Mutable default arguments
def add_item(item, list=[]):  # DON'T!
    list.append(item)
    return list

# ❌ Pitfall 2: Integer division in Python 2
# In Python 2: 5 / 2 = 2
# In Python 3: 5 / 2 = 2.5
# Use: 5 // 2 for integer division

# ❌ Pitfall 3: Comparing floats
if 0.1 + 0.2 == 0.3:  # False!
    print("Equal")

# ✅ Better: Use epsilon comparison
epsilon = 1e-10
if abs((0.1 + 0.2) - 0.3) < epsilon:
    print("Close enough")
```
